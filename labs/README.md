# Power BI Hands-On Labs

Ten progressive, self-contained labs for the WSQ course.

Each folder contains a detailed Markdown/PDF guide, a professional Excel intake/control/evidence workbook, and a Power BI starter file.

| Lab | Level | Output | Folder |
|---|---|---|---|
| 1. Connect, Inspect and Profile an Excel Dataset | Foundation | A profiled query with correct headers, types and documented quality issues | [01-data-intake](01-data-intake/README.md) |
| 2. Clean, Transform, Append and Merge | Foundation | A repeatable Power Query transformation pipeline with an audit trail | [02-power-query](02-power-query/README.md) |
| 3. Choose Visuals for Trends and Correlations | Intermediate | A one-page analytical report using fit-for-purpose native visuals | [03-visual-choice](03-visual-choice/README.md) |
| 4. Design an Accessible Report Story | Intermediate | A polished report page with hierarchy, theme, tooltips and accessible navigation | [04-report-story](04-report-story/README.md) |
| 5. Build an Executive Dashboard and Scorecard | Intermediate | A Sales Monitoring dashboard and KPI scorecard in Power BI Service | [05-dashboard-scorecard](05-dashboard-scorecard/README.md) |
| 6. Create Dynamic Interactions and Navigation | Intermediate | An interactive report with slicers, drillthrough, bookmarks and tested interactions | [06-dynamic-interactions](06-dynamic-interactions/README.md) |
| 7. Model a Star Schema and Date Dimension | Advanced | A semantic model with fact/dimension relationships and a marked date table | [07-star-schema](07-star-schema/README.md) |
| 8. Create Core DAX Measures | Advanced | Validated measures for Sales, Cost, Profit, Margin and share of total | [08-dax-measures](08-dax-measures/README.md) |
| 9. Apply Time Intelligence and Scenario Analysis | Advanced | YTD, prior-period, Top N and what-if analysis with decision commentary | [09-advanced-analytics](09-advanced-analytics/README.md) |
| 10. Deliver the GlobalTech Sales Performance Cockpit | Capstone | A stakeholder-ready PBIX report, dashboard evidence and QA checklist | [10-capstone](10-capstone/README.md) |

## Working convention

1. Download the complete repository ZIP or clone the repository.
2. Open each lab folder locally on a Windows computer with Power BI Desktop.
3. Work on a renamed copy of `starter.pbix` and retain the Excel Evidence sheet.
4. Use the detailed Learner Guide for supporting explanations and cross-lab context.
