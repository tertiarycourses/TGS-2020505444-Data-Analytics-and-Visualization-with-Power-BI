# Data Analytics and Visualization with Power BI

WSQ courseware for **TGS-2020505444**, aligned to Data Visualisation TSC **MED-DIT-4006-1.1**.

[Course information](https://www.tertiarycourses.com.sg/wsq-data-analytics-and-visualization-with-power-bi.html)

## Courseware

- Visual, concept-led PowerPoint deck with editable native PowerPoint charts
- Learner Guide with detailed click-by-click Power BI procedures
- Slide-mapped two-day Lesson Plan
- Ten progressive, self-contained Power BI labs

## Hands-on labs

Each folder under [`labs/`](labs/README.md) contains:

- `README.md` and matching printable `README.pdf`
- a lab-specific Excel intake/control/evidence workbook
- a Power BI `starter.pbix`

The labs progress from data intake and Power Query through visual design, dashboards, interactions, star-schema modeling, DAX, advanced analytics and an integrated capstone.

## Distribution boundary

Public courseware and learner lab materials are stored in this repository. Assessment papers, answer keys, source references, release QA and credentials remain private and are distributed through the approved Drive/LMS workflow only.
