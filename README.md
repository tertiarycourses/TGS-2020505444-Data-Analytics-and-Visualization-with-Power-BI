## About the course

This course teaches you to turn complex data into compelling visual stories with Power BI. You connect to and profile data, clean and shape it in Power Query, choose the right visuals for trends and correlations, build dashboards and scorecards, add dynamic interactions, model a star schema and write DAX measures for analysis. Practical exercises built on a realistic GlobalTech sales dataset run through every topic, ending in an integrated capstone report.

## Learning outcomes

By the end of the course, learners will be able to:

- **LO1** — Perform data transformation techniques using Power BI
- **LO2** — Create data visualization to portray data trends and correlations
- **LO3** — Develop dashboards and scoreboards
- **LO4** — Create dynamic data visualization
- **LO5** — Create data model for strategic visualization and mapping
- **LO6** — Perform data analytics and queries with DAX

## Topics covered

1. Data intake, profiling and transformation with Power Query
2. Choosing visuals for trends and correlations; accessible report design
3. Dashboards and KPI scorecards in Power BI Service
4. Dynamic interactions — slicers, drillthrough, bookmarks and navigation
5. Data modelling — star schema, relationships and date dimensions
6. DAX measures, time intelligence and scenario analysis
